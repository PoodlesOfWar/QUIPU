Loadopoly integrations

SDKs for QUIPU's x_ProcessStudio MCP. A client can read the ledger, stage a proposal (held), and hear the Perceptopoly voice while a human Admin has it on. It cannot authorise or realise: the server has no such tool.

Downloads

  • Python (stdlib only)
  • JavaScript (ES module) and types

Use

from loadopoly_integrations import Client
c = Client("https://YOUR-HOST/mcp", token=TOKEN)
c.propose("hub.body_directive", "line 3 is quiet",
          {"title": "Check line 3", "do_this": "Walk it", "owner_role": "Ops"})

Keep the token out of source control and chat. Plain http is refused for public hosts.
